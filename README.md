# KRiEC-Tech-SIH-2024

**Smart Irrigation and Crop Management System - SIH 2024**

## Overview

KRiEC-Tech-SIH-2024 is a **smart irrigation system** developed for the **Smart India Hackathon 2024**. It is designed to optimize water usage in agriculture by leveraging sensor data, crop information, and weather conditions to determine the precise amount of water needed for irrigation.

## How It Works

The system collects and analyzes multiple data points to make irrigation decisions, including:

- **Sensor Data**: Real-time monitoring of **soil moisture, humidity, and temperature** using IoT sensors.
- **Crop & Soil Type**: Different crops and soil types require different irrigation strategies. The system takes these factors into account for precise recommendations.
- **Weather Data**: Integrates live weather forecasts to adjust irrigation schedules dynamically, preventing overwatering and water wastage.
- **Smart Decision Making**: Uses Firebase and Firestore Database to store and process data, ensuring efficient water distribution based on real-time conditions.

## Technologies Used

- **Backend & Database**: Firebase (Firestore Database)
- **Frontend**: HTML, CSS, JavaScript
- **IoT Integration**: Sensors for soil moisture, temperature, and humidity
- **Weather API**: Fetches real-time weather data for accurate irrigation adjustments
